# 📄 電子公文歸檔自動化系統 (Taipei Official Document Auto-Archiver) `v1.3`

專為 **臺北市政府及所屬各級機關、學校行政同仁** 設計的「電子公文自動歸檔小幫手」。透過 Python、Selenium 與 Tkinter 技術，協助同仁從繁瑣的公文點擊與歸檔流程中解放，實現「批次選取、對照分類、一鍵自動歸檔」。

---

## ✨ 核心特色與 v1.3 重要更新

- **全自動智慧歸檔流程**：
  1. **自動勾選待結案公文**：精確識別並透過 iCheck 勾選目標待辦公文。
  2. **自動點擊「存查」**：自動觸發存查與歸檔表單跳出。
  3. **自動處理「附件歸檔」**：自動點擊「附件歸檔」按鈕，捕捉並切換至新開啟的分頁，並自動完成分頁關閉。
  4. **智慧選擇分類檔號與案次號**：操控原生 HTML 下拉選單 (`q_fsKindno` 與 `q_caseno`)，精確對照代碼選取對應分類與第一項有效案號。
  5. **自動點擊「確定存檔」**：完成欄位填寫後自動點擊「確定存檔」送出歸檔。
  6. **長效憑證簽章監測**：支援「自然人憑證」或「組織憑證」驗證流程，輪詢等待同仁輸入 PIN 碼完成簽章。
- **現代化雙階段 GUI 介面**：採用 Tkinter / ttk 質感介面設計，具備「一鍵批量統一設定分類」、「即時執行日誌 (Live Log)」面板與「視窗常駐置頂」切換。
- **完整公務分類對照庫 (`MASTER_CATEGORIES`)**：內建綜合業務、文書、人事、會計、教務、資訊教學與資安、學務、體育、輔導與特教等近百項權威分類號大辭典。
- **自訂常用分類設定檔 (`categories.txt`)**：啟動時自動載入或生成 `categories.txt`，支援同仁輸入常用分類代碼數字即可自動匹配完整名稱。
- **完全 UTF-8 標準編碼**：全專案原始碼重構，徹底解決舊版中文註解與字典選單亂碼問題。

## 📁 專案主要檔案結構

| 檔案名稱 | 說明 |
| :--- | :--- |
| **`auto_archive_v1.3.exe`** | **主要應用程式**：雙擊即可直接執行（無需安裝 Python 環境）。 |
| **`auto_archive_v1.3.py`** | **核心原始碼**：包含 GUI 介面、分類號資料庫與 Selenium 自動化邏輯。 |
| **`auto_archive_v1.3.spec`** | **PyInstaller 打包規格檔**：用於編譯生成獨立 `.exe`。 |
| **`categories.txt`** | **自訂分類檔**：輸入常用分類代碼數字（每行一個），程式會自動轉換選單名稱。 |
| **`requirements.txt`** | **專案套件依賴檔**：包含 `selenium` 等必要模組。 |
| **`version.txt`** | **版本記錄檔**：記錄目前軟體版本號 (`1.3.0`)。 |

## 🚀 如何使用

### 方法 A：使用執行檔 (`auto_archive_v1.3.exe`) —— 推薦一般同仁使用
1. 雙擊執行 **`auto_archive_v1.3.exe`**。
2. 點擊 **「🌐 1. 啟動專用 Chrome 瀏覽器」**，程式會自動開啟獨立的 Chrome 瀏覽器。
3. **在開啟的 Chrome 視窗中**：
   - 登入臺北市政府電子公文系統。
   - 切換至 **「待結案」** 頁面。
4. **回到程式視窗**：
   - 點擊 **「📥 2. 我已準備好，開始抓取待辦清單！」**。
5. **設定分類**：
   - 針對抓取到的公文，從下拉選單選擇對應的歸檔分類（亦可使用上方「快速統一設定」一鍵套用至全區）。
6. **開始歸檔**：
   - 點擊 **「⚡ 確認分類，開始批次自動歸檔！」**，放開雙手，讓程式全自動執行歸檔！

---

### 方法 B：使用原始碼 (`auto_archive_v1.3.py`) —— 適用開發者
1. **準備 Python 環境** (建議 Python 3.8+)：
   ```bash
   # 啟動虛擬環境 (Windows)
   .\venv\Scripts\activate

   # 安裝依賴套件
   pip install -r requirements.txt
   ```

2. **執行主程式**：
   ```bash
   python auto_archive_v1.3.py
   ```

3. **自行重新編譯 .exe 執行檔**：
   ```bash
   pyinstaller --noconfirm auto_archive_v1.3.spec
   ```

## ⚙️ 進階設定：自訂分類檔 (`categories.txt`)

程式啟動時會自動讀取同目錄下的 `categories.txt`。您可以使用記事本開啟它，輸入您單位常用的分類代碼（每行一個代碼數字）：

```text
# ==========================================
# 電子公文小幫手 - 常用分類設定檔
# ==========================================
03750401
03750402
03750403
03010203
```

下次啟動程式時，下拉選單就會自動顯示這些代碼對應的完整名稱與案號（例如：`03750401-資訊研習及競賽(3年)`），方便快速選取。

## ⚠️ 注意事項與聲明

1. **資安說明**：本程式僅模擬人工瀏覽器點擊與表單填寫，**絕不儲存或傳送** 任何帳號密碼、憑證或公文內容。
2. **視窗常駐置頂**：預設啟用「📌 視窗常駐置頂」，方便您在 Chrome 瀏覽器與操作視窗間隨時切換與檢視進度。
3. **錯誤容錯**：若單筆公文因網路或系統超時發生異常，程式會在日誌面板輸出提示並自動跳過該筆，繼續處理下一筆任務。
4. **授權說明**：本專案僅供學術交流與提升公務行政效率使用，請遵守各機關資安與檔案管理規範。
